# Frequently Asked Questions

## What makes this special compared to other country flag quiz websites?

A few things:

- **Higher Customizability** With several options on how you want to be quizzed, customizable timers, different progression, and much more.
- **Simple interface** Straight to the point.
- **Not restricted to countries.** Beyond sovereign nations, there are categories for US states, territories, international organisations, pride flags, and more to come!
- **A free API.** All the data and flag images are available as static files. See [API.md](API.md).

## Will there be more languages?

Maybe. More languages will need volunteers to help with translations. If you'd like to help, please get in touch and we'll share more details.

## Why are there countries that I've never heard of, or that aren't really countries?

We've decided that to be eligible in a category, a sovereign nation must follow the **Article 1 of the Montevideo Convention** and must be recognized by **at least one UN member state**. This keeps the criteria objective rather than picking sides on disputed cases, so some entries may be unfamiliar or politically contested.

## I found a bug, what do I do?

Please report it at <https://github.com/BaguetteBunny/vxillum/issues>. Include what you did, what you expected to happen, and what actually happened. Your browser and device help too!

## What categories are available?

Africa, Asia, Europe, North America, South America, Oceania, US States, Territories, International Organisations, and Pride Flags. Each one is also available as its own JSON file through the API!

## Is the API free to use? Do I need an API key?

It is completely free to use without any keys. The API is a set of static files you can fetch directly, for example `https://vxillum.com/api/en/index.json`. Full details are in [API.md](API.md).

## What image formats and sizes are available?

Flags are available as SVG, or as PNG at widths of 20, 40, 80, 160, 320, 640, 1280, and 2560 pixels. SVG is best when the image needs to scale. Full details are in [API.md](API.md).

## A flag is missing, wrong, or outdated. Can I suggest a change?

Yes. Open an issue at <https://github.com/BaguetteBunny/vxillum/issues> with the flag, the category it belongs in, and a source if you have one. Suggestions are checked against the criteria above.

## Can I use the flag images in my own project?

Yes, please do!
